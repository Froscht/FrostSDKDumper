SECONDARY FIX (same day, 2026-05-03):

  <= rg.hi` skipped any heap region smaller than 4MB. Heap

  the per-iteration read to `min(WIN, rg.hi - page)` and the
  inner offset cap to `this_win`. With the old 64KB window
  the same bug existed but skipped only <64KB regions
  (negligible).

WHAT SHIPPED 2026-05-04 (Option A — Tier 1 emulation now works)

auto_chunks_emu.h:
  1. Cap lifted 12 → 256 distinct fn_starts. The original cap stopped
     the search at RVA 0x32786A — far short of any chunks-pipeline fn.
     With 256, hit-process counters now show: 256 distinct, 182 dup,
     0 walkback_failed.
  2. Walkback validation: WalkBackToFunctionStart now checks the
     CC-walkback result against LooksLikePrologue (push reg / sub rsp /
     mov [rsp+X], rXX / lea / mov rax,rcx / etc.). On reject, retries
     up to 6× with the previous CC. Removes embedded-CC false starts
     (e.g. 0x2C93EB landed inside a `cmp byte ptr [rip+disp32], imm`
     instruction's disp32). Strict prologue check costs ~nothing — the
     subsequent ~300-µs emulation per candidate dwarfs it.

     MOVAPS /r=05..3D, MOVUPS /r=05..3D. Previous patterns missed any
